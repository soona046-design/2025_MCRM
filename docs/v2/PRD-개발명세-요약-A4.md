# 인사이트 M-CRM — PRD & 개발 명세 요약 (A4 1p)

> 통합 마케팅 성과·고객 관리 CRM 툴 · 기준일 2026-07-22 (v2 배포·운영 중) · 사내 전용 도구

---

## 1. 제품 개요 (PRD)

- **한 줄 정의** — 인사이트가 자사 온라인 광고 성과와 고객 유입~계약 데이터를 한 화면에서 통합 관리·분석하는 **사내 전용** 마케팅 성과 CRM.
- **문제** — 네이버·메타·구글 등 광고 성과가 채널별로 흩어져 있고, 문의~계약(유입 후) 데이터가 광고 데이터와 분리되어 퍼널 효율 판단·주간 보고가 비효율적.
- **해결** — 광고비·노출·클릭·전환은 API 자동 수집(+CSV/수기), 문의~계약은 수기·업로드로 관리 → 하나의 대시보드에서 월간(기본)/주간(경과 확인)/연간 통합 분석·보고서 자동화.
- **타겟 사용자** — 마케팅/영업 팀장(주). 대표·이사(요약 조회), 담당자(입력), 관리자(설정·권한).
- **출시 범위** — 1차: 광고 성과 자동 연동·통합 대시보드 / 유입 단계 관리(수기·업로드) / 맞춤 보고서. 2차 검토: 잠재고객 점수화·개인화 커뮤니케이션.

**핵심 지표(KPI)** — ROAS 8주 내 10%+ 개선 · 주간 보고 작성시간 50%↓ · 데이터 최신성 24h 이내(SLA) · 유입 단계 입력률 90% · 온보딩 완료율 80%.

## 2. 핵심 기능 & 지표 정책

| 영역 | 내용 |
|---|---|
| **통합 대시보드** | 요약 카드 4(ROAS·광고비·전체매출·전환수) + ROAS·ROI 이중축 추이 + 채널 비교 + 5단계 전환 퍼널 + 신뢰도 요약. **메인은 카드·차트만(표 금지)**, 세부 페이지에서 표 제공. |
| **광고 성과 수집** | 채널별 광고비·노출·클릭·전환. 네이버 실 API 자동 수집 운영 중, 메타·구글은 CSV/수기(구글은 Google Ads API 심사 통과 시 자동 전환). 수집 모드는 **정기(매일 06:00)·수동 재수집(하루 3회)** 2종만. |
| **고객 유입 관리** | **5단계 퍼널**(유입 이벤트→리드→상담→견적/제안→계약). 병원명(거래처) 필수·담당자 선택. 수기·CSV 업로드·편집. **유입일 지정 가능**(수기·상세편집·업로드 3경로). |
| **매출 관리** | 계약 등록(신규 유입/기존 고객 구분), 월별 목표 대비 달성률, 추이·기여도. 요약은 **실매출(완료)·예상 매출(진행 중) 분리**(취소 제외). 매출 입력은 매출 관리 화면에서만. |
| **보고서** | 기간·채널 조건 생성, 버전 관리, 발행 시점 **스냅샷 고정**, 매출·ROAS·ROI는 **해당 월 기준** 계산. PDF/Excel 내보내기(권한 제한). |
| **계정·권한** | 관리자 등록 방식 로그인(공개 가입 없음), 첫 로그인 비밀번호 변경 강제, 역할별 접근, 모든 변경 감사 로그(불변). |

**지표 원칙** — ROAS(배)=신규 유입 고객 계약금액÷광고비 → 광고 대시보드 전용. ROI(%)=(전체 매출−광고비)÷광고비 → 매출 관리 전용. 두 지표 동시 표기 시 "신규 유입 기준/전체 포함" 라벨 필수. **결측은 0으로 채우지 않음**(null+사유), 계약 금액 입력률 병기(90%🟢/70~89%🟡/70%↓🔴).

## 3. 개발 명세 (요약)

**스택** — 백엔드 Laravel 12 + MySQL 8 + Redis, 프론트 Next.js. Sanctum 인증. 배포: **VPS 단일 서버 Docker**(app+nginx+mysql+redis+queue+scheduler) + HTTPS + 로그인 게이트, 일일 백업. (Cafe24는 크론·큐·PDF 제약으로 v2 부적합.)

**설계 원칙(코드 계약)** — ① 증거 기반 귀속(UTM/클릭ID/캠페인ID 있으면 confirmed, 없으면 unknown·광고비 미매칭) ② 결측 NULL ③ 월간=집계 기준 단위(소급 시 재계산+로그) ④ 이력 불변(INSERT만) ⑤ 부분 실패 투명성(basis 동봉, 실패 20%+면 data_incomplete) ⑥ 신규/기존 고객 분리 ⑦ 매출 입력 단일 경로 ⑧ 수집 모드 2종 고정.

**주요 테이블** — `users`/`user_permissions`/`permission_logs` · `ad_channels`(토큰 AES-256)/`ad_metrics_daily`/`collection_runs` · `customers`(5단계 stage)/`attribution_evidences`/`change_logs`/`inflow_events`(입력률 KPI) · `contracts`(new_lead/existing)/`existing_customers`/`revenue_goals`/`roas_monthly`(집계 캐시) · `reports`/`report_exports` · `notifications`/`system_settings`/`privacy_logs`.

**주요 API** — `GET /api/dashboard` · `GET /api/collection/status`·`POST …/{ch}/retry` · `GET/POST /api/customers`(금액 필드 없음) · `POST /api/attribution/parse-url` · 업로드 3단계(`/api/uploads`→`/mapping`→`/commit`) · `GET/POST /api/contracts`(customer_type) · `GET/PUT /api/goals/{month}` · `POST /api/reports`(큐) · `/api/notifications` · `/api/settings`.

**배치/잡** — 정기 수집 06:00(3채널·백오프 5/15/30분·최대 3회) · 수동 재수집 · 월 재계산(소급) · 업로드 커밋 · 보고서 생성(PDF/Excel) · 미입력 점검(매시) · 토큰 만료 점검(만료 7일 전 알림) · 만료 익명화(일 1회).

## 4. 화면(1차 = 22개) & 로드맵

- **A 인증·온보딩(4)** 로그인 / 온보딩 3단계(계정 연결·업로드 설정·완료 체크리스트)
- **B 대시보드(3)** 메인 / 채널별 상세(검증용 표) / 캠페인별 상세(귀속률)
- **C 유입 관리(5)** 목록 / 상세(퍼널 타임라인) / 수기 입력 / 파일 업로드 / 미입력·지연
- **D 매출 관리(5)** 계약 목록 / 계약 상세·편집 / 목표 설정 / 추이·기여도 / 기존 고객
- **E 보고서(4)** 목록 / 생성 / 뷰어 / 버전 비교
- **F 설정(5)** 채널 연동 / 사용자 권한 / 개인정보 정책 / 시스템 설정(임계치) / 알림 센터

**로드맵** — B0 인프라 → B1 인증·유입·업로드 → B2 매출·목표·집계 → B3 광고 API 커넥터·귀속 엔진 → B4 보고서·개인정보·온보딩. (프론트 목스토어를 동일 시그니처 API로 교체.)

**현황** — 화면·백엔드 전체 완료 + 통합 검증, VPS Docker로 실데이터 운영 중(문의·광고·매출). 네이버 실 API 자동 수집 운영, 구글 Google Ads API 심사 진행 중.
