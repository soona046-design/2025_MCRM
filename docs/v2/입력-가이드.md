# M-CRM v2 — 전체 입력 가이드 (처음 쓰는 사람용)

> 대상: CRM에 처음 입력하는 팀원. 시나리오 순서대로 따라가면 됩니다.
> 한 줄 원칙: **문의는 유입 관리에, 돈은 매출 관리에, 하루 안에.**
> 심화 문서: [문의-입력-가이드](문의-입력-가이드.md)(광고 증거·UTM), [데이터-갱신-가이드](데이터-갱신-가이드.md)(월별 일괄 갱신 — 관리자용)

---

## 0. 시작 전에 — 딱 3가지 개념

1. **유입 고객 vs 기존 고객** — 문의~계약 전까지는 "유입 고객"(고객 관리), 계약이 성사되면 "기존 고객"(매출 관리)이 됩니다. **전환은 자동**: 첫 매출을 입력하는 순간 기존 고객이 만들어집니다. 따로 옮길 필요 없습니다.
2. **금액은 3종류** — 헷갈리면 여기만 다시 보세요:
   | 이름 | 어디에 | 성격 |
   |---|---|---|
   | 기대매출액 | 유입 관리 | 견적 단계의 **추정치**. 파이프라인 카드에만 합산 — 매출 아님. 예상 비용(선택)을 함께 넣으면 목록·카드가 **순액(매출−비용)**으로 표시 |
   | 계약금액 | 프로젝트(묶음) | 총액 **표시용** (분납 진행률의 분모). **정기는 월액이 기준** — 표에 '월 ₩X'로 표시되고 무기한은 총액이 없음 |
   | 매출금액 | 회차(행) | **실제 집계 기준** — 이것도 '완료(수금)' 처리된 것만 매출로 인식 |
3. **입력하는 화면은 딱 2곳** — 유입 관리(문의 왔을 때)와 매출 관리(돈 얘기가 나올 때). 대시보드·성과 분석·보고서는 전부 자동 계산이라 입력할 게 없습니다.

## 1. 문의가 들어왔다 → 고객 관리 › 유입 고객 › **수기 입력**

**문의 발생 후 24시간 안에** 입력합니다(입력률 KPI 90%).

1. **신규 문의 / 기존 재문의 선택** — 병원명을 입력하기 시작하면 **비슷한 기존 고객이 자동으로 뜹니다**("ㄱ"만 쳐도 굿윌·김해… 검색됨). 우리와 거래 중인 병원이면 **그 항목을 클릭** — 자동으로 '기존 재문의'로 전환되고 고객이 연결됩니다. 기존 고객을 신규로 등록하면 신규 성과 지표가 오염되니 이 제안을 꼭 활용하세요.
2. **필수 입력**: 병원명 · 연락처 · 상담 채널 · 유입 경로 · 단계 · 담당자 (유입일은 기본 오늘 — 소급 입력 가능)
3. **온라인 광고로 들어온 문의**: 광고 상세에 **랜딩 URL을 통째로 붙여넣으면** UTM·클릭ID가 자동 파싱됩니다. 이 증거가 있어야 채널별 ROAS에 잡힙니다 — 자세한 건 [문의-입력-가이드](문의-입력-가이드.md).
4. **선택 입력**: 기대매출액·예상 비용(견적·제안 예상 금액과 예상 지출 — 유입 목록 상단 기대금액 카드에 **순액**으로 합산, 비용은 기대매출액이 있을 때만), 문의 서비스(복수), 메모
5. 재문의를 선택하면 **유입 경로는 묻지 않습니다**(재문의는 마케팅 지표에서 제외되므로 필요 없음).

- **여러 건 한꺼번에**: 유입 고객 › 파일 업로드 (CSV 열 매핑)
- **하지 말 것**: 금액을 메모에 쓰기(→ 기대매출액 필드에), 계약 금액을 여기서 찾기(→ 금액 입력란 자체가 없음 — 매출 관리에서)

## 2. 상담이 진행된다 → 단계만 바꾸면 끝

- 고객 상세에서 **단계**(유입 이벤트 → 리드 → 상담 → 견적/제안 → 계약)를 바꿔주세요. 변경 이력은 자동 기록됩니다.
- **90일간 단계 변화가 없으면 자동 보류** 처리돼 파이프라인 집계에서 빠집니다. 다시 진행되면 단계를 바꾸는 순간 자동 재개됩니다.
- 가망이 없으면 직접 **보류** 처리해도 됩니다.

## 3. 계약이 됐다 → 매출 관리 › 매출 현황 › **매출 직접 입력**

**3-1. 누구의 매출인가**
- **신규 유입**: 유입 고객을 검색해 연결. 기대매출액이 있으면 참고 배지와 함께 금액(예상 비용까지)이 미리 채워집니다(실제 계약 금액으로 고쳐 확정).
- **기존**: 기존 고객 검색. 없으면 그 자리에서 신규 등록.
- 재문의 고객을 고르면 **자동으로 기존 탭 + 연결 고객으로 전환**됩니다(신규 유입 매출로는 서버가 차단).

**3-2. 어떤 형태의 매출인가 — 결정표**

| 상황 | 이렇게 입력 |
|---|---|
| 한 번 하고 끝 (간판 시공, 홈페이지 제작 등) | **비정기** · 회차 1줄 (청구일·금액·비용) |
| 총액을 나눠 받기로 함 (1,000만을 300/400/300) | **비정기** · [+ 회차 추가]로 여러 줄 + 상단에 계약금액(총액) |
| 매달 같은 금액, **언제까지인지 모름** | **정기** · 종료월 비움 = **무기한** |
| 매달 같은 금액, 기간이 정해짐 | **정기** · 시작월~종료월 |
| 정기인데 시작할 때 기계·설치비가 별도 1회 | **정기** + 초기 금액 |
| 같은 병원의 다른 일감 | 새로 입력 (프로젝트명이 다르면 별개 묶음) |

**3-3. 정기 입력 시 꼭 확인할 것**
- 입력란 아래 **"등록 미리보기 — …"** 줄이 실제로 만들어질 회차와 합계입니다. **이 줄이 의도와 다르면 등록하지 마세요.**
- **초기 금액은 비워두는 게 기본**입니다. 진짜 1회성 비용(기계·설치)이 있을 때만 넣으세요. (0을 넣어도 이제 무시되지만, 비우는 게 정확합니다)
- 무기한 정기는 당월까지 회차가 만들어지고, **다음 달부터는 매월 자동 생성**됩니다. 사람은 수금 확인만 하면 됩니다.

**3-5. 등록 직후 상태는 항상 '진행 중'** — 등록만으로는 매출이 잡히지 않습니다. 입금 확인 후 상태를 완료로 바꾸는 순간 매출로 인식됩니다.

**3-4. 비용(지출)**: 회차마다 들어간 비용을 입력하면 순매출이 자동 계산됩니다. 나중에 알게 되면 그때 편집해도 됩니다.

## 4. 청구·수금 — 체크 3개의 의미 (제일 헷갈리는 부분)

매출 현황의 각 회차에는 체크 2개와 상태 1개가 있습니다. **서로 독립이고, 사실대로만 체크하면 됩니다.**

| 액션 | 뜻 | 지표에 미치는 영향 |
|---|---|---|
| **청구서** 체크 | 청구서를 전달했다 | 입금 전이면 **미수금**으로 표시 (수금까지 계속 보임) |
| **지출결의서** 체크 | 지출이 나갔다 | 입금과 무관하게 **그 달 비용으로 차감** |
| 상태 **완료** 처리 | 입금을 확인했다 | **그 달(수금일) 매출로 인식** — 이걸 해야 매출이 잡힘. **상태 배지를 클릭**하면 바로 완료(오늘 수금일)/진행 중 전환 |

- **여러 건 한꺼번에**: 표에서 체크박스로 회차들을 선택하면 상단에 일괄 액션 바가 나타납니다 — 청구서/결의서 일괄 체크, 완료(수금) 일괄 처리(수금일 1개 지정 — 정기 여러 건이 같은 날 입금될 때), 휴지통. 금액 수정·취소는 실수 방지를 위해 개별로만 됩니다.
- 예: 7월에 일 끝내고 청구(청구서 ✔) + 비용 지출(결의서 ✔), 8월에 입금 → 비용은 7월, 매출은 8월. 정상입니다.
- 미수금은 기간 필터와 무관하게 **수금될 때까지 목록에 계속** 나타납니다.

## 5. 정기 서비스 운영 → 매출 관리 › 정기 관리

| 하고 싶은 것 | 방법 |
|---|---|
| 월액 인상/인하 | 해당 정기 클릭 → **월액 변경** (적용 시작월부터, 이전 회차는 보존·이력 자동) |
| 해지 | **종료월 입력** — 다음 달부터 유지율에 이탈로 집계 |
| 회차 금액 예외 정정 | 매출 현황에서 그 회차 금액 클릭 편집 |
| 프로젝트 이름·총액·메모 | 매출 현황 → 프로젝트 편집 |

상단 **유지율 카드** = 전월 정기 클라이언트 중 이번 달에도 유지 중인 비율. 해지를 종료월로 입력해야 정확해집니다.

## 6. 잘못 입력했다면

- **유입 정보**: 고객 상세 → 편집. 무엇을 고쳤는지 이력이 자동으로 남습니다.
- **회차 금액·비용·청구일**: 매출 현황에서 해당 회차 편집 (과거 월을 고치면 지표도 자동 재계산)
- **수금(완료) 처리**: 상태 배지 클릭 → 수금일 선택 팝오버(오늘/전월 말일 퀵픽). 정산자료를 다음 달에 확인하는 경우 **실제 입금일(보통 전월 말일)**로 처리해야 그 달 매출로 잡힙니다 — 클릭한 날이 아니라 입금된 날 기준. 여러 건이면 체크박스 선택 후 일괄 완료(수금일 1개 지정)
- **삭제**: 휴지통으로 이동 — 30일간 복구 가능
- **광고 성과 수기 입력이 막힐 때**: API가 자동 수집한 채널·월은 수기/시트 입력이 차단됩니다(이중 집계 방지 — 정상 동작)

## 7. 입력 안 해도 되는 것 (전부 자동)

광고 성과 3채널 수집(매일 06:00) · 신규 유입 첫 계약 시 기존 고객 전환 · 무기한 정기 당월 회차 생성 · 90일 무활동 자동 보류 · 미수금 카드·알림 · 모든 대시보드/분석/보고서 수치
