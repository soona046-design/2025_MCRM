# manyfast PRD 동기화 대기분 (2026-09-07 기준)

> manyfast MCP 미연결 기간에 확정된 변경의 **PRD 반영용 요약**. 재연결 즉시 이 문서 순서대로 일괄 반영 후 삭제.
> 상세 근거: [프론트엔드-변경사항.md](프론트엔드-변경사항.md) §56~79 · [기능명세서.md](기능명세서.md) · [연동-수정-맵.md](연동-수정-맵.md)

## 1. 회계 원칙 (2026-09-03 사용자 확정 — PRD '매출 인식' 절 교체)

- **모든 금액 = 공급가액(VAT 제외)** 입력. 화면 라벨에 명시, 비용 용어는 '비용'으로 통일(서류명 '지출결의서'만 유지).
- **확정 매출 = 수금일 귀속**(현금주의 관리회계). 대시보드·달성률·추이·스냅샷·보고서 '확정' 전부 수금일 기준.
- **예상 매출 = 청구일 귀속**(구 '매출일' → **'청구일'로 전면 개칭** — 세법상 공급시기와 정합). 지출(비용)은 발생 기준 = 청구일 월 귀속.
- 수금일은 완료 클릭일이 아닌 **실입금일** 기록(운영 규칙). 지출 전용 회차 = 금액 0(미입력과 구분, 서버 자동 정규화).

## 2. 매출 현황 화면

- 상단 카드: **순매출 통합 카드**(메인 확정·수금일 기준 + 예상·청구일 기준 병기, 이중 톤 막대 — 진한 확정/연한 예상 추가분, 분모 max(확정,예상)) / 미수금 / 조회 건수 / 금액 미입력.
- 목록: 청구일 기준 기간 필터 + 기간 밖 **미수금 상시 표시** + **당기간 수금 회차 표시**(타월 청구 포함, '수금 MM-DD' 병기). 미수금 행 옅은 주황 강조+태그.
- 기본 정렬 **고객명 가나다순**. 기간 필터는 화면별 localStorage 유지(새로고침 후에도 고정).
- 조작: 상태 배지 인라인 토글(완료 시 **수금일 팝오버** — 기본 오늘·[오늘][전월 말일] 퀵픽), 청구서/결의서 인라인 체크, **일괄 변경**(청구서/결의서/완료(수금일 지정)/휴지통, ≤200건, 금액·취소는 개별만).
- 전화번호는 모든 표에서 **담당자(고객명) 아래** 표기.

## 3. 정기 매출

- 무기한 정기(종료월 없음) 지원 — `contracts:recurring-roll` 매일 06:05 당월 회차 자동 생성(진행 중). **월말 경계는 endOfMonth**(’-31’ 하드코딩 버그로 9월 매일 복제 사고 → 수정·정리 완료).
- 정기 정보 편집: 시작월(미루기=미청구분 정리·당기기=생성)·종료월(당김/연장/무기한 전환)·청구일(매월 며칠)·서비스명·메모·초기 금액. 다이얼로그 순서: 정기 정보→월액 변경→이력.
- 정기 계약금액 열은 **월액 1급 표기**. 유지율(RecurringRetention: 월 활성=시작≤M≤종료, 해지 제외, 클라이언트 단위) 카드 제공.

## 4. 유입 관리

- **기대금액 = 순액(기대매출액−예상 비용)** 표시(카드·열·상세·정렬 '기대금액 높은순'). 예상 비용은 기대매출액 있을 때만(서버 422). 계약 다이얼로그 프리필·참고 배지에 비용까지. 매출 집계 절대 미포함.
- 목록: 기대금액 열, **현재 단계 인라인 변경**(배지 클릭 드롭다운 — 전진 즉시·계약 시 매출 입력 딥링크 토스트·역행은 사유 확인), 상단 카드(신규 유입 수·기대금액 순액+수식).
- 재문의: 기존 고객 서버 검색 자동완성, 유입 경로 비활성('기타'), 병원명 입력 중 기존 고객 초성 대조→클릭 시 재문의 전환.
- GNB 우측 아바타 = 로그인 사용자 실표기(하드코딩 '김' 버그 수정). ※? 아이콘(온보딩 마법사)의 설정 이동 제안은 **결정 대기**.

## 5. 목표·KPI·보고서 (#53~57 완결)

- 건수 KPI 목표(kpi_goals): 신규 문의(유입월·재문의 제외)/제안(당월 ChangeLog 견적·제안)/계약 — GET/PUT /kpi-goals + summary.
- 클라이언트 이슈 로그(client_notes): 기존 고객 노트, 주간 보고 자동 취합.
- 주간 성과보고 자동 조립(Report 'weekly' 스냅샷): 목표·달성/매출 성과(**총 예상 매출=확정+입금예정+타월 미수금+기대금액, 총액 기준**)/클라이언트 현황/신규 문의/파이프라인.
- 대시보드: 이중 톤 목표 막대(확정 진한/예상 연한, 분모=월 목표), 전환수 카드·TrustSummary 제거, 채널 위젯 2종은 성과 분석›채널별 상세로. IA: 성과 분석 그룹에 목표 관리 통합, 추이·기여도 첫 탭.
